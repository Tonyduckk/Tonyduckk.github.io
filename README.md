# Zhou Yiu Tak — Portfolio

Personal website of Zhou Yiu Tak, a Computer Science undergraduate at the Hong Kong University of Science and Technology, with an extended major in Artificial Intelligence and a minor in Big Data Technology.

[Visit the website](https://tonyduckk.github.io/)

## Overview

The site presents my academic background, technical skills, and ongoing projects in software engineering and computer vision. It uses a minimal monochrome design with responsive layouts and direct email and GitHub links.

## Built with

- HTML5 and CSS3
- Vanilla JavaScript
- Inline SVG icons

No build tools, package installation, or external libraries are required.

## Run locally

Open `index.html` in a browser, or start a local server from the repository root:

```sh
python -m http.server 8000
```

Visit `http://localhost:8000`.

## Project structure

```text
index.html     Page content and structure
styles.css     Typography, layout, and responsive styles
script.js      Navigation and email-copy interaction
favicon.svg    Site favicon
.nojekyll      Static serving on GitHub Pages
```

## Hosting

The site is hosted on GitHub Pages and serves the static files from the repository root.
